自分のプレイリストで、何曲わかる？

1 プレイリスト

公開または限定公開のプレイリストに対応。APIキーを使って50曲ずつ次ページも取得します。Google CloudでYouTube Data API v3を有効にしたAPIキーが必要です。

まだプレイリストを読み込んでいません。

2 出題設定

プレイリストから指定曲数を重複なしでランダム抽出します。音が鳴り始めた瞬間に計測を開始し、「正解！」「不正解」「スキップ」のいずれかを押すまで計測します。再生区間が終わっても回答タイマーは続きます。読み込み時間は含みません。

ランダム位置は動画の長さを取得して決めます。YouTubeの仕様上、実際の開始位置は近いキーフレームに調整されることがあります。
